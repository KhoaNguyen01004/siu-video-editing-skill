# siu-video-editing (skill cho Claude)

Bộ hướng dẫn và công cụ giúp Claude dựng video cho Trường Đại học Quốc tế Sài Gòn (SIU): video recap chuyến đi / sự kiện,
video phát biểu / lời chúc, giao kèm **project CapCut** để khách tự mở và chỉnh sửa.

**Hướng dẫn cài đặt và sử dụng đầy đủ (tiếng Việt, từng bước, có ví dụ):**
https://github.com/KhoaNguyen01004/siu-video-editing-skill

Thư mục này gồm:
- `SKILL.md`: điểm bắt đầu, Claude tự đọc khi bạn nhờ dựng video SIU.
- `references/`: 14 tài liệu hướng dẫn (bài học từ các lần sửa, gu của khách, phong cách SIU, âm thanh, phụ đề, CapCut…).
- `scripts/`: công cụ Python / PowerShell (tạo project CapCut, chỉnh màu, kiểm tra nhạc, phụ đề, khung hình, âm lượng…).
- `templates/build_template.py`: khung dựng project CapCut.

Yêu cầu: Windows 10/11, Python 3.10+, FFmpeg, CapCut cho máy tính (đã thử bản 9.8), thư viện trong `scripts/requirements.txt`.
